# Моя библиотека

Учебный проект на Vue 3 + Vue Router (сборщик Vite). Список книг хранится
в localStorage браузера: книги можно добавлять, искать по названию,
редактировать (двойной клик по карточке) и удалять.

## Запуск для разработки

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```
